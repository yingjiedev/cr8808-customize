首个 CR8808 定制维护基线。包含已验证的 HomeProxy 补丁、GFWList 低内存配置构建支持、逐个及一键排队节点测速、状态日志下载权限修复，以及当前固件所对应的公开依赖归档。

此版本的基础固件仍为 ImmortalWrt 24.10-SNAPSHOT `r0-9a11bb8`，内核 ABI 为 `6.6.137~20a052f3c3e98b3a9ba1a095f81e2725-r1`。这里镜像发布者原有固件与工具，不宣称新编译了固件或修复了该旧内核。

附件用途：

- `cr8808-homeproxy-baseline.zip`：十个运行增量包、八个定制覆盖文件、源码、许可及操作手册；不含个人配置，也不是可直接刷写的固件。
- `immortalwrt-sdk-*.tar.zst`：Linux x86_64 用户态软件交叉编译 SDK，约 217 MiB。
- `immortalwrt-imagebuilder-*.tar.zst`：同版 ImageBuilder，约 72 MiB。
- `immortalwrt-toolchain-*.tar.zst`：同版交叉工具链，约 61 MiB。
- `*-squashfs-factory.ubi`、`*-squashfs-sysupgrade.bin`、`*-initramfs-uImage.itb`：上游原始镜像归档。factory 已在本机路线实测，其余镜像仅完成来源、大小和哈希核对，不表示已验证其刷写路线；按机型、分区和手册选择。
- `cr8808-customize-v0.1.0.tar.gz`：该标签的完整公开仓库快照，包括固件源码、固定 feeds、应用源码、原始包、回滚包及电脑辅助工具。
- `dependencies.lock.json`、`release-manifest.json`、`build-report.json`、`SHA256SUMS`：来源、版本、构建结果与附件校验。
- `LICENSE`、`LICENSING.md`：仓库原创部分采用 GPL-2.0-or-later；第三方组件保留各自原有许可。

下载后核对 `SHA256SUMS`。SDK、ImageBuilder 和工具链均为上游原始二进制附件，哈希与原发布者记录相同。Release 不包含订阅 token、节点、Wi-Fi 密码、测速 API 密钥、设备身份或私有备份。

当前应用补丁维持已实机验证的行为，队列并发为 1、间隔 1 秒。应用包可离线重建，完整固件重新编译仍需补齐配方中的其他源码下载并单独验收。

操作和维护见 [依赖维护手册](https://github.com/yingjiedev/cr8808-customize/blob/v0.1.0/doc/cr8808-dependency-maintenance.md)。
